# 📈 Smart Investment Tool — כלי חישוב פרופיל השקעה

כלי אינטראקטיבי שפיתחתי לסיוע למשקיעים מתחילים להבין את פרופיל הסיכון שלהם — בלי ז'רגון פיננסי.

## 💡 הרעיון

רוב הכלים הפיננסיים מורכבים מדי למשקיע הממוצע.  
רציתי לבנות משהו שבתוך 2 דקות עונה על השאלה: **"איפה אני על סקאלת הסיכון, ומה זה אומר בפועל על הכסף שלי?"**

## ✨ מה הכלי עושה

- **5 שאלות קצרות** על סבילות לסיכון, טווח זמן ומטרה
- **פרופיל אישי** — שמרני / מתון / מאוזן / אגרסיבי
- **הקצאת נכסים מותאמת** — אגח, זהב, S&P 500, NASDAQ
- **מדדים פיננסיים** — תשואה צפויה, סטיית תקן, Sharpe Ratio
- **סימולציית עתיד** — כמה הכסף שלך יהיה שווה בעוד X שנים
- **השוואה בין כל הפרופילים** — כדי שתוכל לראות את ההבדל בבחירות שונות

## 🛠️ טכנולוגיות

- Python
- Streamlit
- Plotly
- NumPy

## 🚀 הרצה מקומית

```bash
pip install streamlit plotly numpy
streamlit run app.py
```

## 📌 הערה

הנתונים מבוססים על ממוצעים היסטוריים בלבד.  
הכלי אינו מהווה ייעוץ פיננסי מוסדר — לפני כל השקעה מומלץ להתייעץ עם איש מקצוע.
